## 🗂️ Estructura del repositorio

A continuación una visión general de las carpetas principales y enlaces rápidos dentro del repositorio (rama `master`):

- [AnsysData](https://github.com/LukasWolff2002/AnsysValidation/tree/master/AnsysData) — Datos y notas relacionadas con las simulaciones de Ansys Fluent (incluye `AnsysData/README.md`).
- [CFDData](https://github.com/LukasWolff2002/AnsysValidation/tree/master/CFDData) — Datos CFD procesados y archivos relacionados.
- [Code](https://github.com/LukasWolff2002/AnsysValidation/tree/master/Code) — Codigos en desarrollo
- [Mojabilidad](https://github.com/LukasWolff2002/AnsysValidation/tree/master/Mojabilidad) — Imágenes/series de ensayos de mojabilidad (carpetas numeradas).
- [PIVData](https://github.com/LukasWolff2002/AnsysValidation/tree/master/PIVData) — Datos PIV crudos y procesados.
- [RockyData](https://github.com/LukasWolff2002/AnsysValidation/tree/master/RockyData) — Simulacion de Rocky y codigos relacionados con Rocky

> Nota: Los enlaces apuntan a la rama `master`. Si trabajas en otra rama, cambia `master` por el nombre de tu rama en la URL.

## ⚙️ Cómo usar

1. Clonar el repositorio:

```bash
git clone https://github.com/LukasWolff2002/AnsysValidation.git
```

2. Revisar los scripts en la carpeta `Code` para ver dependencias y flujo de procesamiento.

3. Para ver notas específicas de datos de entrada y parámetros revisa:

- `AnsysData/README.md` — Consideraciones y parámetros de la simulación.
- `PIVData/README.md` — Detalles sobre las mediciones PIV (si aplica).
